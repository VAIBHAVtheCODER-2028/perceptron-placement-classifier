
# Perceptron Placement Classifier
perceptron-placement-classifier

This repository contains a Jupyter Notebook implementation of the **Perceptron Trick**, applied to a placement classification dataset. 

## Features
- **Algorithm:** Implementation of the Perceptron learning algorithm.
- **Goal:** Classify placement outcomes based on input features.
- **Visualization:** Includes decision boundary plotting for the learned weights.

## How to run
1. Clone this repository.
2. Ensure you have `numpy` and `matplotlib` installed.
3. Open `perceptron_placement_classifier.ipynb` in Jupyter Notebook.
